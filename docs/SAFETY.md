# SAFETY

**Decision-Support Only**:
- Display banner: "Decision-support only. A clinician must approve before patient use."
- The tool provides information; the clinician makes the final decision.

**Refusal Conditions**:
- The discharge note is missing critical sections (e.g., medications, follow-up).
- The note contains contradictory instructions (e.g., two different doses for the same drug).
- The note is too vague to extract any actionable items.

**Synthetic Data Only**:
- All data used in development and testing is synthetic.
- No real patient data is used or stored.
